## Detailed Task Specifications

### Task 1 (DO-09): Multi-Stage Dockerfile & Non-Root Container
- **Target Artifacts:** `infra/docker/Dockerfile.backend`, `infra/docker/Dockerfile.frontend`
- **Checklist:**
  - [x] Multi-stage Node.js build: build stage installs full dependencies, compiles contracts and TypeScript; runtime stage copies only production dependencies and compiled `.js`.
  - [x] Non-root user: backend executes under `USER node` (UID 1000).
  - [x] Production frontend build: Vite build output copied to an unprivileged Nginx image listening on port 8080.
- **Done When:** Images build without root execution and pass container vulnerability scans.

---

### Task 2 (DO-09): Staging Compose Topology & Nginx TLS Proxy
- **Target Artifacts:** `infra/compose/docker-compose.staging.yml`, `infra/nginx/nginx.conf`
- **Checklist:**
  - [x] Compose definition orchestrating `backend`, `frontend`, `app_db`, and `analytics_db`.
  - [x] Strict network isolation: analytics database on private internal bridge inaccessible from the public host.
  - [x] Nginx security headers (`X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Strict-Transport-Security`).
- **Done When:** Full topology starts with `docker compose -f docker-compose.staging.yml up` and serves frontend and API seamlessly.

---

### Task 3 (DO-10): Correlated Request Tracing & Zero-Leak Log Redaction
- **Target Artifacts:** `backend/src/plugins/redaction.ts`, `backend/test/security/log-redaction.test.ts`
- **Checklist:**
  - [x] Propagate or generate `X-Request-ID` across every HTTP request and log entry.
  - [x] Pino redact paths for sensitive request headers (`cookie`, `authorization`), response bodies, and database query parameters.
  - [x] Enforce zero database row dumps in audit and error logs.
- **Done When:** Injected failures, queries, and auth attempts never leak plaintext secrets or customer data to stdout.

---

### Task 4 (DO-10): Prometheus Metrics & Deep Health Probes
- **Target Artifacts:** `backend/src/modules/metrics/metrics.service.ts`, `backend/src/modules/metrics/metrics.routes.ts`, `backend/test/integration/metrics-routes.test.ts`
- **Checklist:**
  - [x] Expose `GET /api/v1/metrics` in Prometheus format.
  - [x] Track latency histograms (p50, p90, p95, p99), HTTP status counters, active DB pool connections, and refusal codes.
  - [x] Deep health probes: `/health/liveness` returns 200; `/health/readiness` verifies active connections to both `appPool` and `analyticsPool`.
- **Done When:** Prometheus scrapper can collect metrics and probes accurately reflect database failure without false positives.

---

### Task 5 (DO-11): Encrypted Backup & Recovery Drill (RPO/RTO)
- **Target Artifacts:** `backend/src/modules/backup/backup.service.ts`, `backend/test/integration/backup-recovery.test.ts`
- **Checklist:**
  - [x] Implement `BackupService` using AES-256-GCM encryption with key derivation (PBKDF2/scrypt).
  - [x] Point-in-time recovery verification script restoring backup dump to test database and confirming data parity.
  - [x] Validate RPO (< 24 hours) and RTO (< 1 hour) constraints.
- **Done When:** Automated test restores encrypted dump and proves zero data loss on recovered artifacts.

---

### Task 6 (DO-12): Expand/Contract Migration Compatibility & Rollback Drill
- **Target Artifacts:** `backend/test/integration/migration-rollback.test.ts`
- **Checklist:**
  - [x] Verify that database migrations do not introduce breaking column drops without a multi-phase transition.
  - [x] Simulate container rollback (running Sprint 5/6 code against latest database migration) and prove backward compatibility.
- **Done When:** Rollback test completes without application crash or data corruption.

---

### Task 7 (DO-13): High-Concurrency Benchmark & Security Egress Lockdown
- **Target Artifacts:** `backend/test/benchmark/concurrency-stress.test.ts`, `backend/test/security/egress-lockdown.test.ts`
- **Checklist:**
  - [x] Automated stress suite testing 20 concurrent queries: verifies p95 latency < 3s and pool concurrency limiter returns HTTP 429 when saturated.
  - [x] Outbound network audit verifying zero outbound external network connections when `PROVIDER_MODE=local`.
- **Done When:** Concurrency stress test passes within latency budgets and egress tests fail closed.
