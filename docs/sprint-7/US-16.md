## Story Narrative

> **As an operator**,  
> **I want** an observable, containerized, non-root staging deployment with zero-leak log redaction, real-time Prometheus telemetry, encrypted backups, verified disaster recovery drills, and rollback mechanisms,  
> **So that** I can diagnose failures, maintain service health, safeguard database credentials and customer PII, and recover cleanly from incidents without data loss.

---

## Acceptance Criteria

- [x] **AC-US16-1 (Non-Root Container Hardening):** Fastify backend and static frontend build as multi-stage, minimal Docker images executing strictly under unprivileged `node` user ID (`1000:1000`) and unprivileged Nginx (`101:101`).
- [x] **AC-US16-2 (Zero-Leak Correlated Logging):** Every incoming HTTP request assigns or propagates an `x-request-id`. Fastify structured logger automatically redacts sensitive headers (`cookie`, `authorization`), database rows, PII, and LLM API keys before writing to stdout.
- [x] **AC-US16-3 (Prometheus Telemetry & Health Probes):** Expose `GET /api/v1/metrics` conforming to Prometheus exposition format tracking:
  - `http_requests_total` partitioned by route, method, and status code.
  - `http_request_duration_seconds` histogram (p50, p90, p95, p99).
  - `db_pool_active_connections` and `db_pool_waiting_clients` across both `appPool` and `analyticsPool`.
  - `guardrail_refusals_total` by refusal code.
  - Detailed `/health/liveness` and `/health/readiness` probes testing database connectivity with fail-closed semantics.
- [x] **AC-US16-4 (Encrypted Backup & Verified Recovery):** Automated metadata backup utility dumps and encrypts `app_db` state using AES-256-GCM. Point-in-time restoration drill restores database state and verifies artifact integrity, proving RTO < 1 hour and RPO < 24 hours.
- [x] **AC-US16-5 (Zero-Data-Loss Rollback Drill):** Database migrations adhere to expand/contract guidelines; deploying a prior backend release against the updated database maintains operational readiness without schema corruption or crash.
- [x] **AC-US16-6 (Performance SLA & Concurrency Limits):** Stress testing with 20 concurrent requests confirms p95 query latency < 3s for analytics execution and guarantees that requests exceeding pool limits receive HTTP 429 rather than hanging.
- [x] **AC-US16-7 (Airgap & Egress Lockdown):** When `PROVIDER_MODE=local`, tests verify zero network egress to external hosts; DNS resolution or socket attempts outside `127.0.0.1` and local Docker network fail immediately.
