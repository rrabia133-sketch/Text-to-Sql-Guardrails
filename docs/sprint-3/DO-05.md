## Objective

Establish secure, least-privilege LLM provider configurations for local Ollama and cloud Groq adapters. Enforce backend credential containment, request deadlines, per-day dollar budget ledgers in `app_db`, and an automated privacy-mode egress test verifying that local-only mode cannot emit outbound traffic to cloud providers.

- **Status:** ⚪ PENDING

- **Checklist:**
  - [ ] Write SQL migration `03-provider-budget-ledger.sql` creating table `provider_usage_ledger` in `app_db`.
  - [ ] Support recording date, provider name, model, prompt tokens, completion tokens, and dollar cost estimates.
  - [ ] Implement query method to compute today's total accumulated cost:
    ```sql
    SELECT COALESCE(SUM(estimated_cost_usd), 0) AS daily_total
    FROM provider_usage_ledger
    ```

  - [ ] Enforce quota gatekeeper rejecting cloud requests before outbound dispatch when `daily_total >= DAILY_CLOUD_BUDGET_USD`.
