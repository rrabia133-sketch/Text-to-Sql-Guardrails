## Objective

Establish reproducible, leakage-free evaluation infrastructure and dataset versioning controls for the Text-to-SQL generation and semantic verification engine. Build an automated benchmark runner that measures semantic accuracy, wrong-answer rates under high confidence, and abstention quality. Enforce strict isolation of the frozen holdout test suite to prevent premature exposure during prompt tuning or semantic rule development, ensuring all release claims are backed by uncompromised empirical evidence.

### [ ] Task 4: Confidence Calibration Ledger & Reliability Binning Report
- **Status:** ⚪ PLANNED
- **Target Artifacts:** `backend/src/modules/evaluation/calibration-report.ts`, `docs/sprint-5/benchmark-report.md`
- **Checklist:**
  - [ ] Group benchmark results into 10 confidence decile bins (0–9, 10–19, ..., 90–100) and the 3 decision bands (`high`, `review`, `blocked`).
  - [ ] Calculate empirical accuracy per bin: `correct_queries / total_queries_in_bin`.
  - [ ] Compute key NFR quality gates:
    - High-Confidence Wrong-Answer Rate: `incorrect_answers_in_high_band / total_high_band_queries` (target: ≤ 5%).
    - Refusal / Clarification Recall: `refusals_on_ambiguous_queries / total_ambiguous_queries` (target: ≥ 90%).
    - False Refusal Rate: `refusals_on_valid_queries / total_valid_queries` (target: ≤ 15%).
  - [ ] Generate markdown summary report `docs/sprint-5/benchmark-report.md` recording model versions, prompt hashes, and calibration findings.
- **Done When:** Automated calibration report generates reliability binning metrics and verifies quality targets.
