## Objective

Enforce strict lifecycle bounds on analytical query result payloads (`15-minute` ephemeral TTL), user query history (`30 days`), and operational audit trails (`90 days`), while guaranteeing that CSV exports neutralize all spreadsheet formula injection vectors (`=`, `+`, `-`, `@`, `\t`, `\r`) and strictly enforce user ownership.

---

## Tasks & Deliverables

### [ ] Task 1: Ephemeral Result Payload TTL (15m) & Memory Bound Enforcement
- **Status:** ⚪ PLANNED
- **Target Artifacts:** `backend/src/modules/execution/result-cache.service.ts`, `backend/test/unit/result-cache.service.test.ts`
- **Checklist:**
  - [ ] Store executed result rows in an ephemeral cache with a strict `15-minute` TTL (`900,000 ms`) rather than persisting customer result rows in `app_db`.
  - [ ] Enforce per-entry row (`500 rows`) and byte (`1 MiB`) bounds.
  - [ ] Return explicit `RESULT_EXPIRED` status (`HTTP 410 Gone`) when an analyst requests export of a result older than 15 minutes.
- **Done When:** Ephemeral result payloads never persist to disk/database and deterministically expire after 15 minutes.

---

### [ ] Task 2: Spreadsheet Formula Injection Neutralization & CSV Security Suite
- **Status:** ⚪ PLANNED
- **Target Artifacts:** `backend/src/modules/export/csv-exporter.service.ts`, `backend/test/security/csv-injection.test.ts`
- **Checklist:**
  - [ ] Neutralize all dangerous leading characters (`=`, `+`, `-`, `@`, `\t`, `\r`) — including values preceded by whitespace — by prefixing a single quote (`'`).
  - [ ] Escape internal double quotes (`"` -> `""`) and wrap fields containing commas, quotes, or newlines in double quotes.
  - [ ] Verify against OWASP CSV injection vectors (`=cmd|' /C calc'!A0`, `+SUM(1,1)`, `-2+3+cmd`, `@IMPORTXML(...)`, `\t=1+1`).
- **Done When:** All OWASP spreadsheet formula injection vectors are neutralized and verified by automated security tests.

- **Status:** ⚪ PLANNED
