## Story Narratives

### US-13 — Preview and Explicit Run Control
> **As an analyst**,  
> **I want** to inspect the generated SQL, resolved date periods, referenced schema objects, and model assumptions before explicitly clicking Run, with idempotency and version freshness guarantees,  
> **So that** I retain full control over database execution and stale, altered, or unapproved artifacts can never be executed.

### US-14 — Readable Typed Results, Accessibility & Bounded Safe CSV Export
> **As an analyst**,  
> **I want** a clear, keyboard-accessible result table that preserves PostgreSQL data types and visually distinguishes `NULL`, empty (`0 rows`), truncated (`> 500 rows` / `1 MiB`), and failed states, along with an owner-verified CSV download that neutralizes spreadsheet formulas,  
> **So that** I can safely inspect and export analytical answers into spreadsheets without formula injection risks.

### US-15 — Private Query History, Feedback & Retention Controls
> **As an analyst**,  
> **I want** a private, paginated history of my past questions and artifacts with the ability to reload, delete, or submit `correct`/`incorrect` feedback, backed by automatic retention cleanup (`15m` ephemeral results, `30d` history, `90d` audit logs),  
> **So that** I can revisit my prior work and flag issues while keeping my data private and compliant with retention limits.

## Acceptance Criteria

### US-13 (Preview and Run)
- [x] **AC-US13-1 (Full Preview Visibility):** SQL text, referenced tables/columns, resolved temporal range (`startDate`, `endDate`, `timezone`), and assumptions are displayed before execution.
- [x] **AC-US13-2 (Artifact Immutability & Version Freshness):** Client SQL replacement, expired artifacts (`> 15m`), or artifacts generated under an outdated `schemaVersion` / `policyVersion` are rejected before execution.
- [x] **AC-US13-3 (Idempotent Execution):** Repeated execution requests carrying the same `idempotencyKey` return the existing execution result rather than dispatching duplicate database queries.

### US-14 (Results, CSV Export & Accessibility)
- [x] **AC-US14-1 (Typed & Distinct Result States):** Result table renders numbers, booleans, dates, and strings with appropriate formatting and explicitly distinguishes `NULL` cells, `0-row` empty results, `truncated` results, `timed_out`, and `failed` states.
- [x] **AC-US14-2 (Bounded Safe CSV Export):** `GET /api/v1/executions/:id/export.csv` verifies execution ownership, enforces the 15-minute ephemeral result window, preserves row/byte truncation bounds, and neutralizes cells starting with `=`, `+`, `-`, `@`, `\t`, or `\r` by prefixing a single quote (`'`).
- [x] **AC-US14-3 (WCAG 2.2 AA Accessibility):** Question -> Preview -> Review Modal -> Results journey is navigable via keyboard (`Tab`, `Enter`, `Escape`), announces status transitions via `aria-live`, and uses text/icon cues alongside color badges.

### US-15 (History, Feedback & Retention)
- [x] **AC-US15-1 (Paginated Owner-Scoped History):** `GET /api/v1/history` returns paginated (`limit`, `offset`) artifacts strictly owned by the authenticated user; cross-user lookup or deletion (`DELETE /api/v1/history/:artifactId`) is rejected with `403`/`404`.
- [x] **AC-US15-2 (Analyst Feedback Isolation):** `POST /api/v1/queries/:id/feedback` records `verdict` (`correct` | `incorrect`), `reasonCode`, and optional `notes` linked to the artifact without modifying benchmark ground-truth files.
- [x] **AC-US15-3 (Retention Enforcement):** Ephemeral execution result payloads expire after 15 minutes (`RESULT_EXPIRED` on export/fetch), and the retention service purges history older than 30 days and audit logs older than 90 days.
